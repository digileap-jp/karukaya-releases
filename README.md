# Karukaya（カルカヤ）

AI CLI（Claude Code、Codex など）で開発する人のための、軽いデスクトップエディタです。
AI が書き換えたファイルをすぐに見つけ、差分を確かめ、次の指示を出せます。

**今はベータ版です。** 動きや画面が予告なく変わることがあります。不具合や気付いたことは、Karukaya を教えてくれた人に知らせてください。

## できること

- **AI CLI をそのまま動かす**：右下のターミナルで、Claude Code や Codex などをいつもどおり使えます
- **変わったファイルが分かる**：AI が書き換えたファイルには、ツリーに印が付きます
- **差分を確かめる**：変わったところを、色分けして見られます
- **作業を止めない**：AI がファイルを書き換えても、確認なしで読み込み直します
- **パスから開く**：ターミナルに出た `src/foo.ts:12` のようなパスを、クリックでその行に開けます
- **指示をメモで書く**：長い指示はメモに書いて、ターミナルに送れます
- **WSL・SSH のフォルダも開ける**：サーバーのフォルダでも、手元と同じように使えます

使い方は、下の「[使い方](#使い方)」を見てください。

## ダウンロード

[Releases](https://github.com/digileap-jp/karukaya-releases/releases/latest) から、使っている OS のファイルをダウンロードしてください。

| OS | ファイル |
|---|---|
| Windows 11 | `Karukaya_<版>_x64-setup.exe` |
| Mac（Apple シリコン・Intel のどちらも） | `Karukaya_<版>_universal.dmg` |
| Linux（Ubuntu 22.04 以降・Debian） | `Karukaya_<版>_amd64.deb` |

新しい版が出ると、起動したときにステータスバーの右端に「新しい版 vX.Y.Z があります」と出ます（0.1.4 から）。押すと、ダウンロードのページを開きます（Mac は、入れ直すコマンドをコピーします）。それより前の版を使っている人は、ときどき Releases を見てください。

## 入れ方

Karukaya には、まだ電子署名をしていません。そのため、最初に開くときに OS が警告を出します。次の手順で進めてください。

### Windows

1. `Karukaya_<版>_x64-setup.exe` を開く
2. 「Windows によって PC が保護されました」と出たら、「詳細情報」を押し、「実行」を押す
3. あとはセットアップの案内に従う

消すときは、「設定」→「アプリ」→「インストールされているアプリ」から Karukaya をアンインストールします。

### Mac

**ターミナルで入れる（おすすめ）**：次の 1 行を実行します。最新の版を「アプリケーション」に入れ、最初に開くときの警告も出ません。新しい版にするときも、同じ 1 行を実行します（Karukaya を「終了」（⌘Q）してから。窓を閉じただけでは、Karukaya は終わっていません）。

```bash
curl -fsSL https://raw.githubusercontent.com/digileap-jp/karukaya-releases/main/install-mac.sh | sh
```

途中で「ターミナルで karukaya . と打って起動できるようにしますか？」と聞かれます。`y` を押すと、Mac のパスワードを聞かれます。中で何をしているかは [install-mac.sh](install-mac.sh) で読めます。

**ブラウザでダウンロードして入れる**：

1. `Karukaya_<版>_universal.dmg` を開き、Karukaya を「アプリケーション」にドラッグする
2. 「アプリケーション」の Karukaya を開く。「開けません」「Apple は検証できませんでした」と出たら、「完了」（または「OK」）で閉じる
3. 「システム設定」→「プライバシーとセキュリティ」を開き、下のほうの「"Karukaya" は Mac を保護するためにブロックされました」の横の「このまま開く」を押す
4. もう一度出る確認で「このまま開く」を押し、Mac のパスワードを入れる

2 回目からは、普通に開けます。うまくいかないときは、ターミナルで次を実行してから開いてください。

```bash
xattr -dr com.apple.quarantine /Applications/Karukaya.app
```

### Linux

```bash
sudo apt install ./Karukaya_<版>_amd64.deb
```

アプリの一覧から Karukaya を開けます。消すときは `sudo apt remove karukaya` です。

## ターミナルから起動する

フォルダに移って `karukaya .` と打つと、そのフォルダを Karukaya で開けます。`karukaya src/main.ts` のようにファイルも開けます。Karukaya がもう動いているときは、その Karukaya に新しい窓で開きます。

- **Windows**：セットアップで使えるようになります。セットアップの後に開いたターミナルで使ってください（Windows Terminal は、アプリごと開き直します）
- **Mac**：Karukaya のメニューの「Karukaya」→「ターミナルから起動できるようにする…」を一度押します（Mac のパスワードを聞かれます）。0.1.7 までに押した人は、もう一度押してください（前のままでも開けますが、Karukaya をもう 1 つ起動してから、動いている Karukaya に渡すので、少し遅くなります）
- **Linux**：`.deb` を入れると使えます

## エクスプローラーから開く（Windows）

エクスプローラーでファイルやフォルダを右クリックし、「Karukaya で開く」を選ぶと、Karukaya で開けます。フォルダの中の何もないところで選ぶと、そのフォルダを開きます。

- Windows 11 では、右クリックで最初に出るメニューにはなく、「その他のオプションを確認」の中にあります（Shift を押しながら右クリックすると、すぐに出ます）
- ファイルは、右クリックの「プログラムから開く」→「Karukaya」からも開けます。いつも開くアプリは変わりません
- セットアップで使えるようになり、アンインストールで消えます

## Finder から開く（Mac）

Finder でファイルを右クリックし、「このアプリケーションで開く」→「Karukaya」を選ぶと、そのファイルのあるフォルダごと Karukaya で開けます。Karukaya がもう動いているときは、新しい窓で開きます。

- フォルダは、右クリックからは開けません。ターミナルで `karukaya .` と打つか、Karukaya で「フォルダを開く」から選んでください

## 使い方

ショートカットは Windows・Linux のものです。Mac では Ctrl を ⌘（Cmd）に読み替えてください（ターミナルのタブの切り替えなど、Mac でも Ctrl のものはそう書いています）。

### 基本の流れ

1. **フォルダを開く**（Ctrl+O）。右下のターミナルが、そのフォルダで起動します。新しいプロジェクトなら、フォルダを選ぶ画面の「新しいフォルダー」（Mac は「新規フォルダ」）で作ってから選べます
2. **ターミナルで AI に指示する**。`claude` や `codex` を、いつものターミナルと同じように動かします
3. **変わったファイルを見つける**。AI が書き換えたファイルには、ツリーに印が付きます（青＝変更、緑＝追加、赤＝削除）
4. **差分を確かめる**（Ctrl+Shift+D）。開いているファイルの変わったところを見られます
5. 気になるところがあれば、**次の指示を出す**

### ツリーのキー操作

ツリーでファイルやフォルダを 1 回クリックして選んでから使います。

- **開く**：Enter（Mac は ⌘↓）。ダブルクリックでも開きます
- **名前を変える**：F2（Mac は Enter）
- **ゴミ箱に入れる**：Delete（Mac は ⌘Delete）
- **コピー**：Ctrl+C（Mac は ⌘C）。デスクトップやエクスプローラー・Finder で貼り付けると、そこにコピーされます。右クリックの「コピー」でも同じです（SSH の先のファイルは、この PC にないのでできません）

### 変わったファイルを見つける

- ツリーの上の件数を押すと、変わったファイルだけを表示します。もう一度押すと元に戻ります
- Git で管理しているフォルダでは、何と比べた変更かを、作業の状況に合わせて選びます
  - main などから分かれたブランチ：分かれた地点からの変更（PR になる部分）
  - まだ push していないコミットがあるとき：push した地点からの変更
  - それ以外：フォルダを開いたときからの変更
- Git で管理していないフォルダでは、フォルダを開いてから変わったファイルを並べます（差分は出せません）

### 差分を見る

- **変わったところを見る**（Ctrl+Shift+D）：上の「何と比べた変更か」と、今のファイルを比べます。もう一度押すと閉じます
- **HEAD との差分**：コマンドパレット（Ctrl+Shift+P）の「HEAD との差分を見る」で、最後のコミットと比べます
- **変更のある場所**：差分を見ているときは、スクロールバーの横の細い帯に、変更のある場所の印が出ます（青＝変更、緑＝追加、赤＝削除）。帯を押すと、その場所へ移ります。長いファイルで、どこまでスクロールすればよいかが分かります

### AI がファイルを書き換えたとき

- 自分が編集していないファイルは、**確認なしで読み込み直します**。カーソルの位置とスクロールは、できるだけそのままにします
- 自分の未保存の編集があるファイルだけ、エディタの上に知らせが出ます。「自分の編集を残す」「外部の変更を取り込む」「差分を見る」から選べます（ダイアログは出ないので、作業は止まりません）

### ターミナル

- **パスを開く**：ターミナルに出た `src/foo.ts:12` や `C:\work\foo.ts:12:5` のようなパスを、Ctrl+クリックすると、その行を開きます
- **URL・フォルダを開く**：`http://localhost:5173` のような URL は、Ctrl+クリックでいつものブラウザで開きます。`docs/` のようなフォルダは、ツリーでそのフォルダまで開いて見せます（開いているフォルダの外なら、エクスプローラー・Finder で開きます）
- **行の場所を入れる**：エディタで Ctrl+Shift+Enter（Mac は ⌘⇧Enter）を押すと、選んだ行の場所（`src/foo.ts:12-30`、選んでいなければ今の行）をターミナルに入れます。続けて「ここは何をしている？」などと打てば、AI にその場所のことを聞けます。右クリックの「選んだ行の場所をターミナルに入れる」でも同じです
- **改行**：Shift+Enter で、送らずに改行できます（Claude Code・Codex など、Alt+Enter で改行できる CLI）
- **タブ**：Ctrl+Shift+T（Mac は ⌘T）で新しいターミナル。Ctrl+Tab・Ctrl+Shift+Tab で切り替えます
- **コピー・貼り付け**：文字を選んで Ctrl+C でコピー（選んでいなければ、いつもどおり中断）、Ctrl+V で貼り付け

### メモから AI に指示する

- Ctrl+N で新しいメモを作ります。メモは、**タブを開いている間だけの下書き**です
  - メモは、開いているフォルダごとに分かれます。フォルダを切り替えると、そのフォルダのメモに替わります
  - メモは、開いているフォルダの中には作りません（Karukaya のデータフォルダに置きます。メニューの「メモ」→「メモのフォルダを開く」で開けます）。フォルダの中にファイルを作るときは、ツリーの上の「⋯」か、ツリーの右クリック、「☰」メニュー（Mac はメニューバー）の「ファイル」→「新しいファイル」を使います
  - タブを開いている間は、Karukaya を閉じても中身は消えません（次に起動したときも残っています）
  - タブを閉じるときに「消す」を選ぶと、中身は消えます。残したいときは「名前を付けて保存」（Ctrl+Shift+S）で、ファイルとして保存してください
- 指示を書いて Ctrl+Enter を押すと、選んだ部分（なければ今の行）をターミナルに送ります。貼り付けと同じ扱いなので、複数行でも、ターミナルで Enter を押すまで実行されません（貼り付けに対応したシェルや AI CLI の場合）
- 長い指示を推敲したり、前に出した指示を使い回したりするのに便利です

### 探す

- **コマンドパレット**（Ctrl+Shift+P）：コマンドやファイルを名前で探して開けます。どのコマンドがあるか分からないときも、ここから探せます
- **フォルダ内を検索**（Ctrl+Shift+F）・**置換**（Ctrl+Shift+H）。置換の直後なら、「検索」→「直前のフォルダ内の置換を元に戻す」で戻せます（置換の後に書き換えられたファイルは戻しません）
- **ファイル内を検索・置換**（Ctrl+F）、**行へ移動**（Ctrl+Alt+G）

### Markdown

- Ctrl+Shift+V で、Markdown を整えた表示を右に並べます。`mermaid` のコードブロックは図になります

### HTML

- ツリーかタブで `.html` のファイルを右クリックし、「ブラウザで開く」を選ぶと、いつものブラウザで開きます。AI に作らせた 1 枚の HTML をすぐに見たいときに使います。WSL のフォルダのものも開けます（SSH の先のものは開けません）
- AI が書き換えたら、ブラウザで読み直してください（F5 など）。自動では読み直しません
- CSS や画像が出ないときは、`/css/style.css` のようにサーバーに置く前提の書き方になっていることがあります。ファイルを直接開くときは `css/style.css` のような相対パスでないと読めないので、AI に「ブラウザでファイルを直接開いて見られるように、CSS や画像は相対パスで」と頼んでください

### WSL・SSH のフォルダ

- **WSL**（Windows）：「☰」メニューの「ファイル」→「WSL のフォルダを開く」。ターミナルは WSL の中のシェルで起動します
- **SSH**：「☰」メニューの「ファイル」→「SSH のフォルダを開く」。`~/.ssh/config` のホストから選べます。接続先は Linux（x86_64・arm64）です。最初につなぐとき、Karukaya がサーバーに小さなプログラムを置きます

フォルダを開いていないときの最初の画面からも開けます。Mac では、「☰」メニューの代わりにメニューバーを使います。

### ヘルプ

F1（Mac はメニューの「ヘルプ」）で、使い方と、すべてのショートカットの一覧を見られます。バージョンは、「ヘルプ」の「Karukaya について」で確かめられます。

## 設定

設定は `settings.json` に書きます（設定画面はまだありません）。コマンドパレットの「設定ファイルを開く」で、Karukaya の中で開けます。Karukaya の中で書き換えて保存すると、すぐに反映されます。新しい版で増えた項目は、起動したときに初期値で書き足されます。

```json
{
  "appearance": { "theme": "dark" },
  "ui": { "fontSize": 13 },
  "tree": { "fontSize": 15 },
  "editor": { "fontFamily": "", "fontSize": 14, "wordWrap": false },
  "terminal": { "fontFamily": "BIZ UDGothic", "fontSize": 14 }
}
```

| 項目 | 意味 |
|---|---|
| `appearance.theme` | 配色。`"dark"`（初期値）、`"light"`、`"system"`（OS の設定に合わせる） |
| `editor.fontFamily`・`terminal.fontFamily` | フォントの名前。空なら既定のフォント。カンマで区切って複数書ける |
| `editor.fontSize`・`terminal.fontSize` | 文字の大きさ（px）。初期値は 14。Markdown の整えた表示は、エディタの大きさに合わせる |
| `ui.fontSize` | タブ・見出し・ステータスバー・メニューなど、エディタとターミナル以外の文字の大きさ（px）。初期値は 13 |
| `tree.fontSize` | ツリーの文字の大きさ（px）。`null`（初期値）なら `ui.fontSize` に合わせる |
| `editor.wordWrap` | 長い行を折り返すか。Alt+Z（Mac は Option+Z）でも切り替えられる |
| `startup.folder` | 起動したときに開くフォルダ。`"last"`（初期値。最後に開いていたフォルダ）、`"none"`、またはフォルダのパス |
| `terminal.macOptionIsMeta` | Mac のターミナルで、Option キーをメタキーとして使うか。初期値は `false` |
| `update.check` | 起動したときに、新しい版があるかを調べるか（GitHub に問い合わせる）。初期値は `true`。新しい版があれば、ステータスバーの右端に出る |

**ターミナルで日本語の字間が空くとき**：英数字と日本語の幅がちょうど 1:2 のフォント（`BIZ UDGothic`。Mac・Windows に最初から入っています）を `terminal.fontFamily` に指定すると、そろいます。

文字の大きさは、Ctrl+＋ / Ctrl+− / Ctrl+0 でも変えられます（フォーカスがある場所（エディタ・ターミナル・ツリー）だけ）。

## 入っていないもの

Karukaya は、AI CLI と一緒に使う「軽いエディタ」に絞っています。次のものは入っていません。

- AI とのチャット画面（AI はターミナルの AI CLI で使います）
- コミットやブランチの切り替えなどの Git の操作（ターミナルで行います。差分を見ることはできます）
- コードの補完、定義へのジャンプ（LSP）、デバッガー、拡張機能
